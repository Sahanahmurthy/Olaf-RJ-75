# Olaf RJ-75 — Design D1 (-10% Parametric Regional Jet)

**Course:** Aircraft Performance and Design (V Semester Mini Project)  
**Institution:** Department of Aerospace Engineering, Dayananda Sagar University, Bengaluru  
**Author:** Sahana H Murthy (USN: ENG24AS0056) — Team 09  
**Faculty Mentor:** Dr. Srinath R  

## Overview
This repository archives the engineering models, aerodynamic analyses, flight performance scripts, and 6-DOF flight simulation files for **Design D1 (*Olaf RJ-75*)**, the $-10\%$ downscaled supercritical T-tail regional jet ($\text{MTOM} = 44{,}946\text{ kg}$, $S = 83.673\text{ m}^2$, $b = 25.623\text{ m}$, $AR = 7.632$).

## Repository Contents
* **`D1_Olaf_RJ75_Dossier.pdf`** — Individual Design & Simulation Dossier
* **`video-fg.mp4`** — FlightGear 2024.1.7 + JSBSim 6-DOF flight-test recording
* **`openvsp/`** — Parametric 3D CAD geometry (`.vsp3`) and VSPAERO polar outputs
* **`xflr5/`** — Supercritical airfoil polars (`vimana_0714`, `vimana_0710`) and `.xfl` project file
* **`jsbsim/`** — JSBSim Flight Dynamics Model (`olaf-rj75.xml`) and FlightGear aircraft configuration
* **`scripts/`** — Python scripts for ISA flight performance, field length, and V–n envelope analysis
